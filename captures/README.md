# Captures

Raw BLE captures used to derive `FreelapProtocol.mc`. One folder per session:
`YYYY-MM-DD-<chip-or-firmware>/` containing the tshark TSV export, the run
script that was followed (see docs/REVERSE-ENGINEERING.md), and the MyFreelap
values noted for each run. Never commit anything containing a phone's
identifying data beyond the chip's own address.
